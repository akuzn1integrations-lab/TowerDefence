# Высокодетализированный пакет графики

В каталоге `assets/generated/` игра ищет необязательный файл `manifest.json`, описывающий 23 WEBP-спрайта, восемь WEBP-биомов и иллюстрацию колонии.

## Установка

1. Возьмите `NOVA7-graphics-pack.zip` из приложенных к выпуску файлов.
2. Распакуйте содержимое в **корень репозитория**, так чтобы файл располагался по пути `TowerDefence/assets/generated/manifest.json`.
3. Запустите `npm start` и откройте игру. Графика загрузится автоматически, а объекты и карты будут отображаться из WEBP.
4. Если пакет не установлен или браузер не может загрузить изображение, игра продолжит работать со встроенным Canvas/SVG-художественным набором.

## Состав

- `hero.webp` — большая иллюстрация колонии на Нова-7
- `biomes/biome-01.webp`…`biome-08.webp` — посадочная долина, кремниевые ущелья, болота, разлом, плато, гигантский лес, дюны и кратер
- `towers/` — шесть башен
- `traps/` — три ловушки
- `units/` — разведдрон, экзопехота, ремонтный бот
- `enemies/` — одиннадцать существ, включая боссов
- `manifest.json` — таблица URL, которую читает `loadOptionalRasterArt()`

Формат WEBP уменьшает общий вес исходных изображений, не меняя баланс и размер клеток. Высокодетализированные спрайты вырезаны из разработанных листов концепт-арта; отдельные анимационные фазы не реализованы, а попадания, HP, замедление, выделение и трассы оружия остаются игровыми Canvas-эффектами.

**Ограничение:** подробный архив графики поставляется отдельным скачиваемым пакетом, а не хранится в текущих Git-коммитах. В Git есть полнофункциональный встроенный SVG/Canvas-слой, точная схема подключения и тесты. Для строго автономного релиза с WEBP-ассетами следует распаковать архив и создать отдельный Git-коммит с `assets/generated/`.
