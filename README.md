# TowerDefence — Экспедиция Нова-7

**Играбельный MVP из шести секторов** на чистом JavaScript (ES Modules, HTML5 Canvas 2D, CSS). Без игровых движков, фреймворков, сборки и серверной логики. Доступен в браузерах компьютеров и телефонов.

## Быстрый запуск

Требуется **Node.js 20+**:

```bash
npm start
```

Откройте **http://localhost:4173**. Также подходит любой статический HTTP-сервер, который обслуживает корень проекта. Не используйте `file://` — ES Modules могут блокироваться политикой безопасности браузера.

Проверки:

```bash
npm run check
npm test
```

`npm install` не нужен: runtime и тесты не зависят от внешних пакетов. Ветка `main` проверяется через GitHub Actions.

## Состав MVP

| Сектор | Миссия | Главное нововведение |
|---|---|---|
| **01 · Первая линия** | Защита генератора и монтаж купола | Кинетические турели, 3 волны, обучение |
| **02 · Геологический пост** | Защита геосканера | Бронированные Кремнепанцири, импульсный излучатель |
| **03 · Сигнал за холмом** | Удержание исследовательского маяка | Быстрые Рывуньи, ловушки, разведдроны, пауза сканирования при угрозе |
| **04 · Каменный коридор** | Доставка группы и удалённый монтаж | Два наземных входа, гаубица с уроном по области |
| **05 · Небесная тень** | Удержание станции наблюдения | Воздушные Парокрылы и зенитные посты |
| **06 · Путь образцов** | Сопровождение группы до эвакуации | Мобильная научная группа с остановками, три направления атаки |

Сектора последовательно открываются после **первой победы** в предыдущем. Все шесть доступны для неограниченных повторов. После шестой победы появляется экран завершения первой главы. Максимум — **18 звёзд**.

### Башни, ловушки, мобильные отряды

- **4 башни:** кинетическая, импульсная, гаубица «Гром» и зенитная; уровни I–III, продажа за 60% вложенной энергии.
- **2 ловушки:** одноразовая электромина и замедляющее поле с двумя зарядами.
- **Разведдрон:** до двух активных, перемещение по команде, автономная стрельба по наземным целям, собственное здоровье.
- **4 врага:** Искрошмыг, бронированный Кремнепанцирь, Рывун, воздушный Парокрыл.
- Прорыв к цели приводит к кратковременной (до 2,5 секунд) контактной атаке; затем животное отступает **без награды за убийство**. Это ограничивает наказание за единичный прорыв.

### Кампания и экономика

- Каждая победа даёт от 1 до 3 звёзд: обязательная победа и две явно указанные дополнительные цели. Хранится **лучший** результат.
- Первая успешная вылазка в каждом секторе приносит обычную награду и крупную **разовую** премию. Повторы — только обычную награду; поражения не расходуют материалы или научные данные.
- **3 постоянных исследования:** точный привод (+10% кинетического урона), энергетический конденсатор (+15% импульсного урона), полевое снабжение (+100 стартовой энергии).
- Сюжетно необходимое вооружение открывается **автоматически** и бесплатно до первого обязательного применения: импульсная башня для сектора 02, ловушки и дрон для 03, гаубица для 04, ПВО для 05.
- Прогресс, просмотренные брифинги, рекордные звёзды, материалы, данные и исследования сохраняются локально в **localStorage**, с миграцией с вертикального среза v1 на схему v2.

## Как играть

1. Нажмите **«Начать экспедицию»** → «Карта планеты» → выберите доступный сектор.
2. При первом входе прочитайте **брифинг** из нескольких кадров. Его можно открыть повторно на карте и во время миссии.
3. Выберите турель на панели справа (на узком экране — под полем), затем коснитесь **светящейся строительной площадки** и подтвердите кнопку «Построить».
4. Для ловушки выберите янтарную отметку **на дороге**. Для дрона — выберите тип «Разведдрон» и любую разрешённую клетку. Чтобы переместить дрон, выберите его на поле → «Переместить дрон» → укажите точку назначения.
5. Запустите первую волну. После окончания волны нажмите запуск следующей. Во время боя можно строить, улучшать и продавать, ставить на паузу и переключать **1× / 2×**.
6. Держите критический прибор или исследовательскую группу в живых и дождитесь завершения научной задачи. После победы вернитесь в лагерь для постоянных улучшений.

**Управление:** указатель/тап — выбор; перетаскивание — панорамирование карты; два пальца или кнопки **±** — масштабирование; пробел — пауза, `WASD` — движение камеры, `Esc` — отмена выделения. На телефоне строительство всегда требует подтверждения, чтобы случайный тап не тратил ресурсы.

## Границы версии

Реализована **первая глава MVP (01–06)**, но не 12 секторов полного релиза. Вторая глава (07–12), особые существа (вожак, босс), крио-маяк, экзопехота, ремонтный бот и другие биомы остаются последующими этапами. Нет сетевой синхронизации, внутриигровых покупок и процедурной генерации.

Для выпуска на широкую аудиторию рекомендуется провести отдельное **ручное тестирование браузерного интерфейса на реальных мобильных устройствах** и плейтесты баланса. Автоматическая проверка кода и игровой логики не заменяет эту проверку.
