# TowerDefence · Экспедиция Нова-7

**Версия 0.3.0: полная играбельная кампания из 24 секторов в 8 биомах.** Научно-фантастическая Tower Defence на чистых JavaScript ES Modules, HTML5 Canvas 2D и CSS. Без фреймворков, игровых движков и серверной логики.

## Как запустить

Нужен Node.js 20+. Ничего устанавливать через npm не требуется:

\`\`\`bash
npm start
\`\`\`

Откройте **http://localhost:4173**. Можно использовать другой статический HTTP-сервер. Не открывайте \`index.html\` через \`file://\` — браузеры могут блокировать ES Modules.

Проверки:

\`\`\`bash
npm run check
npm test
npm run smoke
\`\`\`

Команда \`smoke\` использует Chrome/Chromium, если он установлен, и проверяет реальный интерфейс на настольном и мобильных размерах экрана.

## Кампания: 8 глав, 24 сектора

| Биом | Сектора | Главные испытания |
|---|---:|---|
| Посадочная долина | 01–03 | Первая оборона, броня, ловушки и дрон |
| Кремниевые ущелья | 04–06 | Гаубица, воздушные враги, сопровождение |
| Светящиеся болота | 07–09 | Крио-маяк, вожаки, ретрансляторы |
| Тектонический разлом | 10–12 | Экзопехота, Разломники, Глубинный титант |
| Кристальное плато | 13–15 | Резонатор и смешанные наземно-воздушные волны |
| Кроны гигантов | 16–18 | Акустические приманки и защита экспедиций |
| Обсидиановые дюны | 19–21 | Ремонтный бот, сложные маршруты |
| Кратер сияния | 22–24 | Финальная сеть, Матриарх разлома |

Каждый сектор имеет собственный 4-кадровый брифинг, отдельные волны и карту, научную цель, условия для трёх звёзд и награды. Сектора открываются последовательно, после победы в предыдущем. Сектора доступны для неограниченных повторных прохождений, но **крупная премия даётся только за первую победу**. Соберите до **72 звёзд**.

По окончании сектора 24 выводится финал — экспедиция создаёт безопасную систему миграции местной фауны в обход колонии. Полное описание и таблица всех миссий: [docs/CAMPAIGN_24.md](docs/CAMPAIGN_24.md).

## Боевые возможности

- **6 башен:** кинетическая турель, импульсный излучатель, гаубица «Гром», зенитный пост, крио-маяк, резонансная установка. Каждая имеет три уровня и может продаваться за 60% потраченной полевой энергии.
- **3 ловушки:** электромина, замедляющее поле, акустическая приманка.
- **3 мобильных отряда:** разведдрон, экзопехота, ремонтный бот. Отряды перемещаются по приказу. Ремонтный бот чинит приборы, исследователей и союзников, если находится поблизости.
- **11 видов животных**, включая быстрые, бронированные, летающие, сигнальных вожаков и двух больших противников.
- **5 типов научных задач:** монтаж стационарного прибора, удержание зоны сканирования, доставка прибора с группой специалистов, сопровождение, последовательная активация трёх ретрансляторов.
- **9 постоянных исследований** в лагере: боевые улучшения, улучшения отрядов, экипировки и дополнительное снабжение.
- Башни и отряды, необходимые для сюжета, открываются бесплатно **перед первой обязательной миссией**, где они понадобятся. Повторный фарм валюты для сюжетного прохождения не требуется.

### Управление

1. Меню → **Лагерь** → **Карта планеты** → выберите доступный сектор. При первом входе откроется брифинг; позднее его можно читать снова через карту и архив.
2. Выберите башню или отряд на панели снаряжения, коснитесь подходящей клетки и нажмите **«Построить»**. Светящиеся клетки — для башен, янтарные отметки на дороге — для ловушек.
3. Для перестановки мобильного отряда выберите его на карте → **«Переместить отряд»** → нажмите на новую точку.
4. Запускайте волны по очереди; следите за HP критического объекта и за прогрессом научной задачи. Во время боя доступны строительство, улучшения, продажа, пауза и скорость 2×.
5. После победы получите звёзды и ресурсы, улучшите базу и откройте следующий сектор.

Камера: перетаскивание мышью/пальцем, колёсико/жест двумя пальцами или кнопки ± для масштаба, \`WASD\` для прокрутки, пробел для паузы, Esc для отмены. На мобильных устройствах покупка всегда требует отдельного подтверждения.

В верхней панели есть **Архив** (пройденные и будущие секторы, энциклопедия видов и повтор брифингов) и **Настройки** (громкость процедурного звука/музыки, уменьшение анимаций).

## Техническая структура

| Путь | Назначение |
|---|---|
| \`src/config.js\` | Сектора 01–06 и общая регистрация игрового контента |
| \`src/campaign-24.js\` | Сектора 07–24, сценарии волн, новые виды, оборудование, исследования |
| \`src/model.js\` | Независимая от DOM игровая симуляция, боевые эффекты, научные задачи |
| \`src/progress.js\` | Награды, 24 сектора, localStorage, миграция v1/v2 → v3 |
| \`src/visual.js\` | Canvas 2D, визуализация 8 биомов, врагов и науки, адаптивная камера |
| \`src/main.js\` | UI экранов, навигация, система брифингов, HUD и игровой цикл |
| \`src/audio.js\` | Процедурные Web Audio эффекты и музыка |
| \`tests/model.test.js\` | Регрессионные тесты, включая сквозное прохождение всех 24 секторов |
| \`tests/browser-smoke.mjs\` | Проверки Chromium: реальное строительство, экраны и адаптивность |

Сохранения локальные, **без серверной синхронизации**. Ключ хранилища прежний (\`towerdefence-nova7-v1\`), схема расширена до v3: старые достижения секторов 01–06 сохраняются; после победы в секторе 06 открывается сектор 07. Удаление данных сайта удалит локальное сохранение.

## Текущее качество и ограничения

Автоматические тесты проверяют механику игры и сквозное прохождение всех секторов **без приобретения платных постоянных улучшений**. Browser smoke тестирует основные пользовательские сценарии на Chromium и разные размеры экрана. Это не заменяет ручных плейтестов баланса и проверок на физических Android/iOS-устройствах.

Стилистика пока реализована геометрическими Canvas/CSS-объектами; для коммерческого релиза можно заменить их финальными ассетами, сохранив игровую логику. Онлайн-функций и монетизации нет.
