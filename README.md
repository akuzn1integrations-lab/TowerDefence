# TowerDefence · Экспедиция Нова-7

Играбельный **вертикальный срез** научно-фантастической Tower Defence на чистом JavaScript без фреймворков и игрового движка.

## Запуск

Требуется Node.js 20+. Не нужны npm install и внешние зависимости.

\`\`\`bash
npm start
\`\`\`

Откройте **http://localhost:4173**. Также можно раздавать корень проекта любым статическим HTTP-сервером (например, \`python3 -m http.server 4173\`). Не открывайте \`index.html\` через \`file://\`: браузер может заблокировать ES Modules.

\`\`\`bash
npm test
npm run check
\`\`\`

## Что уже работает

- Главное меню, лагерь, карта первой области и стартовый **4-кадровый брифинг** с повторным просмотром.
- Сектор 01 «Первая линия»: 20×12 клеток, 18 строительных площадок, три детерминированные волны Искрошмыгов.
- Кинетические турели: строительство за 100 ЭС, автоматическое наведение, улучшения до 3 уровня, продажа с возвратом 60% расходов.
- Отражение нападения и научный таймер монтажа купола (**80 игровых секунд**); проигрыш при гибели генератора.
- От 1 до 3 звёзд: победа, сохранение ≥60% генератора, прохождение без повреждений.
- **Первая победа**: 500 материалов, 50 данных; **повторные**: 180 материалов, 20 данных.
- Постоянное улучшение лагеря «Точный привод I» за 250 материалов: +10% урона кинетических башен в будущих миссиях.
- Сохранение прогресса в localStorage, включая лучшую оценку, ресурсы, просмотр брифинга и исследование.
- Пауза, скорость 1×/2×, адаптивное поле Canvas 2D с панорамированием и масштабированием; UI для мыши, клавиатуры и касаний.

**Как играть:** начните экспедицию → откройте карту → сектор 01 → изучите брифинг → нажмите на одну из светящихся клеток и подтвердите установку башни → запустите волну. После каждой из первых двух волн запустите следующую. Для победы отразите все три и завершите монтаж. На телефоне используйте кнопки масштаба +/- в правом нижнем углу поля; перетаскивание пальцем двигает карту.

## Ограничения вертикального среза

Это **не полная версия MVP** из [плана](docs/IMPLEMENTATION_PLAN.md). Пока реализована только одна миссия и один тип башни/врага. Сектор 02 помечен как обнаруживаемый, но недоступный для запуска: он появится при выполнении следующих этапов. Ловушки, дроны, броня, ПВО, и другие 5 миссий первой главы остаются задачами будущих итераций.

Сохранения хранятся **только в данном браузере**. Их может удалить очистка данных сайта. Проект не требует интернета для симуляции и не передаёт игровой прогресс на сервер.

## Устройство проекта

| Файл | Назначение |
|---|---|
| \`src/config.js\` | Статические данные первого сектора, волны, экономика, брифинг |
| \`src/model.js\` | Независимая от DOM тактическая симуляция и правила боя |
| \`src/progress.js\` | Локальные сохранения, награды, исследования |
| \`src/visual.js\` | Canvas 2D, камера и управление указателем |
| \`src/main.js\` | Состояния экранов, браузерный UI и игровой цикл |
| \`styles.css\` | Адаптивная вёрстка и визуальный стиль |
| \`tests/model.test.js\` | Unit и интеграционные тесты игровой логики |
