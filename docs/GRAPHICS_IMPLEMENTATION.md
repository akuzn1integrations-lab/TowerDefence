# Графическое обновление NOVA–7 · 0.4.0

**Дата:** 29 октября 2026  
**Область:** все 24 сектора, восемь биомов, меню, лагерь, карта, брифинги, архив, тактическое поле, результаты и интерфейс обороны.

## 1. Результат

Переход от условной геометрии и символов к единой графике научно-фантастической колонии:

- **Меню и лагерь** — сцена космического поселения, центральный реактор, защитный купол, шлюзы, подсветка, биом. В Git хранится самостоятельная векторная иллюстрация `assets/art/frontier.svg`.
- **Карта** — главы с иллюстрированными секторами восьми цветовых биомов, подсветка открытых/выбранных/запертых зон и текстовая карточка текущей миссии.
- **Брифинги** — графика научного сканера поверх миниатюрного изображения текущего биома; сохраняются пошаговые кадры, переключение и повторное воспроизведение.
- **Архив** — изображения обнаруженных животных из того же игрового слоя, с названиями и характеристиками.
- **Поле** — детализированный грунт, просчитанные дороги и строительные площадки, подсвеченный генератор, визуализация научной группы и ретрансляторов, мини-карта, здоровье, дальность, трассы выстрелов и области применения.
- **Снаряжение** — единая графика 6 турелей, 3 ловушек и 3 мобильных отрядов; при строительстве та же модель появляется на поле.
- **Противники** — 11 разных силуэтов, отдельные крылья, бронированные корпуса, споровые мешки, отличимые боссы.
- **HUD** — циановые рамки, тёмные панели, улучшенные полосы HP, карточки строительства, подсветка выбранной башни, сенсорные размеры и реакции кнопок.
- **Анимации и доступность** — мягкие пульсации и подсветка, но в режиме reduced motion остаётся вся необходимая визуальная информация без декоративных эффектов.

## 2. Модули

| Путь | Назначение |
|---|---|
| `docs/ART_DIRECTION.md` | Нормативный визуальный стиль, палитры и этапы |
| `src/art.js` | Общий графический API: тайлы, башни, ловушки, отряды, враги, генератор, превью биомов |
| `src/visual.js` | Быстрый Canvas с кэшем местности, кликами, жестами, камерой и мини-картой |
| `art-style.css` | Художественное оформление страниц, карты, брифинга, HUD и мобильной версии |
| `assets/art/frontier.svg` | Иллюстрация лагеря и космического поселения |
| `assets/generated/README.md` | Инструкция по установке опционального растрового пакета |
| `tests/art.test.js` | Проверка всех видов рисунков, биомов, детерминизма и загрузки WEBP |
| `tests/browser-smoke.mjs` | Браузерная проверка иллюстрированных сцен, карты, карточек и адаптивных экранов |

## 3. Растровый пакет

Подготовлен отдельный архив `NOVA7-graphics-pack.zip` (около 1,2 МБ) с WEBP-текстурами из разработанной графики: 23 игровых объекта, восемь биомов и ключевая заставка. Пакет имеет 32 игровых изображения плюс файл манифеста.

**При установке** (распаковать архив в корень репозитория) загрузчик в `src/art.js` считывает `assets/generated/manifest.json`, загружает файлы и подменяет детерминированные Canvas-рисунки полноценными растровыми спрайтами. Загрузка асинхронная, не блокирует игру. Если файла нет, ошибка загрузки не нарушает интерфейс, миссии и сохранения.

Важное различие: **сам архив WEBP находится в приложенном файле, а не в Git**. Исходный репозиторий уже имеет играбельный самостоятельный графический SVG/Canvas-слой. Для распространения именно растрового варианта можно распаковать архив в рабочее дерево и дополнительно зафиксировать графические файлы в Git.

## 4. Разделение этапов и коммитов

Каждый этап внедрялся отдельными коммитами, без переписывания боевых правил.

1. Концепция: `docs/ART_DIRECTION.md`, `src/art.js`.
2. Страницы: `assets/art/frontier.svg`, `art-style.css`, оформление домашнего экрана/лагеря.
3. Карта/брифинги/архив: изображения восьми биомов и найденной фауны, стили этих экранов.
4. Уровни: полный тактический рендерер и кэшированная геометрия местности.
5. HUD/мобильная адаптация: единые иконки, карточки исследований, подсветки и эффекты.
6. Интеграция WEBP, регрессионные тесты и документация.

## 5. Приёмка

```sh
npm run check
npm test
npm run smoke
npm start
```

В `npm test` есть проверки 8 палитр, всех типов спрайтов, предсказуемости ландшафта, режима уменьшенной анимации, корректного манифеста и всей боевой кампании из 24 миссий. `npm run smoke` использует настоящий Chromium, проверяя отрисованные пиксели, изображения интерфейса, путь от меню до боя, карту, строительство и 6 размеров окна.

## 6. Ограничения

Это **полнофункциональная игровая графика** для текущего HTML5-проекта, но не покадровая 3D-анимация. Векторный слой максимально читабелен в тактической камере; растровый пакет даёт дополнительную детализацию, но использует по одному спрайту на тип сущности. Для художественного релиза высокого бюджета потребуются отдельные анимационные атласы, полноценные сюжетные иллюстрации каждого кадра, ручная проверка масштаба спрайтов и плейтесты на физических устройствах.
