# Вертикальный срез — сектор 01 «Первая линия»

**Версия:** 0.1.0 · **Дата:** 2026-10-25 · **Статус:** код и тестовые сценарии добавлены в репозиторий.

## Игровой маршрут

`Главное меню → лагерь → карта → стартовый брифинг → подготовка → 3 волны → экран результата → лагерь`

При первом входе в сектор автоматически показывается брифинг (4 кадра). Просмотр или пропуск записываются в сохранение. По кнопке брифинг доступен повторно. Во время миссии повтор брифинга не уничтожает текущую попытку.

В подготовке доступно 400 единиц энергии снабжения. Игрок размещает кинетические турели на подсвеченных площадках, затем вручную запускает первую волну. После каждой из первых двух волн следующая запускается отдельно. Турели автоматически выбирают ближайшего к генератору врага из доступных в радиусе. Доступны три уровня, продажа, пауза и скорость 2×.

Победа: три волны уничтожены, 80 игровых секунд монтажа закончились, генератор сохранил HP > 0. Поражение: HP генератора 0. Звёзды за победу / ≥60% HP / отсутствие повреждений. Первая победа выдаёт 500 материалов и 50 данных; повторная — 180 материалов и 20 данных. Из лагеря покупается технология «Точный привод I» (+10% урона) за 250 материалов. Состояние сохраняется в localStorage.

## Реализованные файлы

- `index.html`, `styles.css`: страницы, HUD, адаптивный интерфейс и Canvas.
- `src/config.js`: настройки сектора, маршрута, волн, брифинга и экономики.
- `src/model.js`: детерминированная симуляция, проверка размещения, башни, бой и исход.
- `src/progress.js`: постоянный прогресс и защита от повреждённых сохранений.
- `src/visual.js`: поле, камера, панорамирование и выбор клетки.
- `src/main.js`: управление экранами и игровым циклом.
- `tests/model.test.js`: девять автоматических тестов и полный прогон трёх волн.
- `server.js`, `package.json`, `.github/workflows/ci.yml`: локальный запуск и проверки в GitHub Actions.

## Проверочные команды

```sh
npm run check
npm test
npm start
```

Тесты покрывают достижимость маршрута, строительство, экономику, уровни башен, волны, звёзды, первую награду, покупку технологии, сохранение и выигрыш сектора на базовом снаряжении. Дополнительно вручную следует проверить браузерный UX: ввод мышью и касаниями, портретный/альбомный экран, масштабирование, потерю фокуса, новую игру, повтор брифинга.

## Отличия от полного MVP

Срез **не** охватывает сектора 02–06, ловушки, дронов, импульсный/артиллерийский/зенитный тип башен, броню, отдельные биомы и сценарии сопровождения. Кнопка сектора 02 намеренно заблокирована как будущий контент. Разработка перечисленного запланирована последующими этапами [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

По окончании среза предоставлен рабочий сценарий первой миссии, но достижение всех требований полного MVP ещё не заявляется.
