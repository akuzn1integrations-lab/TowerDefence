# MVP 0.2.0 — первая глава TowerDefence

**Статус:** реализованный игровой MVP (сектора 01–06).  
**Дата:** 25 октября 2026 года.  
**Основные документы:** [GDD](GAME_DESIGN.md), [техническое ТЗ](TECHNICAL_SPEC.md), [план](IMPLEMENTATION_PLAN.md).

## 1. Что поставлено

Рабочий игровой цикл: **меню → лагерь → стратегическая карта → обязательный первый брифинг → подготовка обороны → волны и научная задача → итоги → награды → улучшения в лагере → следующий сектор**.

Все шесть секторов доступны последовательно, имеют брифинги, отдельные карты, волны, научную цель, два дополнительных условия звёзд, первую и повторную награды и собственный результат в сохранении.

| ID | Задание | Новые механики |
|---|---|---|
| 01 | Защитить первый генератор до монтажа | Кинетические турели, 3 волны |
| 02 | Оборонять геологический сканер | Кинетическая броня, энергетические импульсы |
| 03 | Удерживать маяк и зону сканирования | Быстрые враги, ловушки, разведдрон |
| 04 | Доставить оборудование и удержать площадку монтажа | Подвижная группа, два наземных входа, гаубица |
| 05 | Защитить станцию от наземных и воздушных атак | Зенитный пост, отдельный воздушный маршрут |
| 06 | Обеспечить эвакуацию исследовательской группы | Маршрут учёных с остановками, атаки с трёх направлений |

В лагере доступны три постоянные технологии: **Точный привод I**, **Энергетический конденсатор** и **Полевое снабжение**. Сюжетное вооружение открывается бесплатно в нужный момент; обязательный фарм между секторами не нужен.

## 2. Реализованные технические требования

- Runtime: нативные ES Modules, Canvas 2D, HTML/CSS, без игровых и UI-фреймворков.
- Симуляция: фиксированный шаг 1/60 секунды, пауза, скорость 1×/2×, отдельные игровые таймеры.
- Разные соотношения сторон: DPR-aware Canvas, ResizeObserver, панорамирование, зум колёсиком, двумя пальцами и кнопками.
- Постройка через предпросмотр и подтверждение, проверка типа клетки и состояния ресурсов, три уровня башен и продажа.
- 4 башни, 2 ловушки, 1 тип мобильного юнита, 4 вида фауны.
- Научные цели: обычный монтаж, удержание безопасной зоны, доставка и удалённый монтаж, сопровождение группы.
- Экран архива: доступные секторы, повтор брифингов, известные виды и их параметры.
- Экран настроек: музыка, звуки, уменьшение анимаций; аудио синтезируется через Web Audio API и необязательно для победы.
- Экран итогов, лучшие звёзды и начисление ресурсов с однократной первой премией.
- Сохранения в localStorage: схема версии 2, миграция прогресса вертикального среза версии 1.
- Разделение контентных данных (`config.js`), правил симуляции (`model.js`), прогресса, визуализации и интерфейса.

## 3. Проверки качества

Команды из корня:

```bash
npm run check
npm test
npm run smoke
npm start
```

`npm run check` проверяет синтаксис исходных модулей. `npm test` запускает проверки секторов, наград, миграции, технологий, типов зданий, ловушек, дронов, целей, сохранений и интерфейсных элементов. Среди тестов есть **полное детерминированное прохождение 01–06 без дополнительных повторов для получения ресурсов**.

`npm run smoke` запускает опциональную проверку настоящего Chromium/Chrome через DevTools Protocol (если браузер установлен): меню, лагерь, карта, брифинг, запуск волны, пауза, выход, архив, настройки, сохранение и узкий мобильный viewport 390×844. GitHub Actions выполняет те же команды.

## 4. Разъяснения и упрощения

- При контакте с критическим объектом существо наносит периодический урон **до 2,5 секунд**, затем отступает без награды. Это ограничивает наказание за один прорвавшийся отряд. Механика отличается от изначальной бесконечной контактной атаки и намеренно зафиксирована в README.
- У наземных противников заранее заданные маршруты. Башни строятся **только вне** этих маршрутов, поэтому полное перекрытие пути невозможно. Для будущих уровней со свободным строительством потребуется полноценное динамическое перепрокладывание пути.
- У сопровождения учёные движутся по заданным путевым точкам с короткими остановками; отдельный симулятор отрядов учёных в лагере не реализуется.
- Художественный стиль выполнен геометрическими Canvas/CSS-элементами. Финальные спрайты, портреты и иллюстрации брифингов заменены техническими визуализациями. Это не блокирует игровой цикл.
- Аудио — процедурное, без лицензионных медиафайлов; пользователь может отключить его.
- Сохранения локальные; удаление данных сайта удаляет сохранения, серверной синхронизации нет.
- Полная кампания из 12 секторов и сюжетный финал всей планеты **не входят** в MVP. Экран после сектора 06 честно отмечает завершение **первой главы**.

## 5. Приёмка и остающаяся ручная проверка

Автоматические проверки не заменяют самостоятельные мобильные плейтесты. Перед публичным выпуском на широкий круг устройств рекомендуется вручную проверить: физические телефоны на iOS/Android, переход портрет ↔ альбом, читабельность и нажатие кнопок на маленьких экранах, регулировку аудио, длительную игру с паузой и возвращением из фоновой вкладки, поведение при ограничении localStorage, баланс для игроков без опыта TD.

Релиз MVP означает завершение **игровых возможностей первой главы**, но не заявляет о готовности всей истории (сектора 07–12) или о прохождении исследований UX/баланса на большой выборке игроков.

## 6. Следующее развитие после MVP

Контент 07–12: болота, разлом миграции, крио-маяк, акустические ловушки, экзопехота, ремонтный бот, сигнальный вожак, Глубинный титант и финальная миссия. Данные и интерфейс первых шести миссий структурированы так, чтобы расширение добавлялось конфигами и небольшими системными возможностями.
