# TowerDefence — план разработки и приёмки

**Версия:** 1.0 · **Статус:** базовый план для разработки, оценки и декомпозиции задач.  
**Связанные материалы:** [GDD](GAME_DESIGN.md) и [техническое ТЗ](TECHNICAL_SPEC.md).

## 1. Соглашения

- **MVP** = полноценная игра первой главы с шестью законченными миссиями (сектора 01–06), а не только техническое демо одной волны.
- **Полный релиз** = 12 секторов, четыре биома, дополнительные системы и сюжетный финал.
- Оценки времени и численные метрики требуют проверки командой; данный документ не обещает календарные сроки.
- Каждая задача считается завершённой, когда есть работающая реализация, проверка пограничных случаев и обновлённая документация.
- Не реализовывать декоративные возможности ранее устойчивого основного цикла и сохранений.
- Изменения в GDD, вызванные плейтестами, отмечать в changelog или через историю Git; игровые числа хранить в конфигурации.

## 2. Рекомендуемая последовательность

| Этап | Цель | Результат | Зависимости |
|---|---|---|---|
| E0. Основа | Запуск, структура, тесты | Приложение с Canvas и HTML UI, работающим resize | Нет |
| E1. Тактическое ядро | Первая оборона | Сетка, камера, путь, враги, башня, волны, победа/поражение | E0 |
| E2. Первый вертикальный срез | Сектор 01 от брифинга до итогов | Лагерь, карта, брифинг, сохранение, звёзды, награды | E1 |
| E3. Тактическое разнообразие | Вторая и третья миссии | Броня, второй тип башни, ловушки, дрон, удержание | E2 |
| E4. Остальная глава MVP | Сектора 04–06 | Много входов, артиллерия, ПВО, сопровождение | E3 |
| E5. Отладка и выпуск MVP | Удобство и устойчивость | Адаптивность, баланс, доступность, производительность | E4 |
| E6. Полная кампания | Сектора 07–12 | Дополнительный контент, финальная глава | E5 |

Можно параллельно создавать концепт-арт, тексты брифингов и звуки, но интегрировать ассеты по мере завершения функциональных механик.

## 3. Epic E0 — фундамент

### Задачи

- [ ] Создать index.html, ES Modules, базовый CSS, минимальный README с командами запуска.
- [ ] Поднять Canvas 2D, DPR-aware масштабирование, ResizeObserver, очистку и игровой цикл.
- [ ] Создать центральный роутер экранов и отдельное состояние игры.
- [ ] Ввести общий модуль валидации конфигов и тестовую инфраструктуру.
- [ ] Организовать загрузчик изображений с placeholders и безопасное отключение аудио.

**Definition of Done:** страница запускается через локальный сервер, смена ориентации не искажает Canvas, тесты запускаются одной командой, на экране есть управляемый переход «Меню → Лагерь → Карта».

## 4. Epic E1 — боевой прототип

### Задачи

- [ ] Сетка с типами клеток, отрисовкой маршрута, строительными площадками.
- [ ] Поворот/масштаб камеры и преобразование координат указателя.
- [ ] A*/BFS, проверка всех входов на достижимость при строительстве.
- [ ] Враги: Искрошмыг, HP, скорость, награда, контактное повреждение.
- [ ] Кинетическая турель: предпросмотр, покупка, автоматическая стрельба, радиус и приоритет.
- [ ] Полевой ресурс, продажа и уровни башни I–III.
- [ ] Волны с детерминированным расписанием и межволновой паузой.
- [ ] Базовая научная цель (монтаж), завершение миссии, пауза и 2×.

**Definition of Done:** тестовый сценарий воспроизводимо завершается победой или поражением; построить башню поверх маршрута невозможно, если это перекрывает единственный путь; пауза действительно замораживает врагов и таймеры.

## 5. Epic E2 — цельная первая миссия

### Задачи

- [ ] Планетарная карта и статусы секторов.
- [ ] Слайдовый брифинг на 4 кадра, первое автоматическое воспроизведение и повтор по кнопке.
- [ ] Реализовать конфиг сектора 01: 3 волны, генератор, монтаж 80 секунд, 2 дополнительных условия.
- [ ] Экран итогов с вычислением текущих/лучших звёзд и прозрачными наградами.
- [ ] LocalStorage, версия схемы, защита от порчи сохранения, подтверждение «Новой игры».
- [ ] Лагерь с мастерской/лабораторией и хотя бы одним постоянным улучшением.
- [ ] Обучение первому строительству и запуску волны.
- [ ] Разделение обычных наград и первой премии без возможности дублирования.

**Definition of Done:** игрок запускает новую игру, просматривает брифинг, проходит сектор, получает награды и разблокировку следующего; после обновления вкладки данные сохранены, повтор брифинга доступен, повторная победа не начисляет бонус второй раз.

## 6. Epic E3 — расширение до первых трёх секторов

### Задачи

- [ ] Типы урона, сопротивления и бронепробитие.
- [ ] Импульсный излучатель и Кремнепанцирь.
- [ ] Ловушки: электромина и замедляющее поле, заряды, статусы.
- [ ] Рывун как отдельная быстрая угроза.
- [ ] Разведдрон: выбор, движение, стрельба, предел отрядов и уничтожение.
- [ ] Удержание датчика с приостановкой научного прогресса при угрозе.
- [ ] Конфиги, волны, брифинги и звёзды секторов 02 и 03.
- [ ] Архив врагов и объяснение типов урона.

**Definition of Done:** разные виды защиты решают разные задачи; в секторе 03 достижимы три звезды; ввод отряда работает мышью и касанием; нет отрицательного баланса при быстрой последовательности команд.

## 7. Epic E4 — завершение первой главы

### Задачи

- [ ] Сектор 04: два входа, гаубица, удалённый монтаж.
- [ ] Сектор 05: Парокрыл, воздушные маршруты, зенитный пост; оружие гарантированно доступно до воздушной волны.
- [ ] Сектор 06: группа исследователей, маршрутные точки, остановки работы, эвакуация, условия потерь.
- [ ] Сохранение прогресса всех шести секторов и лучших звёзд.
- [ ] Разные уровни сложности и наборы волн, минимум 2 биома.
- [ ] Глава MVP завершается отдельным сообщением; шесть будущих миссий отображаются как ещё не реализованные, а не доступные для запуска.
- [ ] Экран архивных брифингов, статусы открытых технологий, итоги всей главы.

**Definition of Done:** все 6 миссий можно пройти подряд с чистого сохранения без обязательных повторов для добычи ресурсов. Маршруты, задачи и сопротивления отображаются до момента, когда игроку надо на них реагировать.

## 8. Epic E5 — качество и выпуск MVP

### Задачи

- [ ] Проверить сценарии 360×800, 390×844, 800×360, 768×1024, 523×523, 1920×1080 и фактические мобильные устройства.
- [ ] Панорамирование, масштабирование и подтверждение строительства на тачскрине.
- [ ] Keyboard-only навигация UI и доступные текстовые подсказки.
- [ ] Музыка/звуки, регулировки, выключение анимаций.
- [ ] Оптимизация с измерением FPS, проверки фона/возврата, rotation, высокого DPR.
- [ ] Провести плейтесты, скорректировать цены, HP, таймеры, длину и состав волн.
- [ ] Проверить отсутствие тупиков в дереве технологий.
- [ ] Ручной и автоматический регрессионный прогон, документация известных ограничений.

**Definition of Done:** пройдены автоматические тесты, нет известных блокирующих дефектов, на целевых мобильных экранах доступны все игровые действия, существующие сохранения загружаются после обновления версии.

## 9. Epic E6 — полноценная кампания

### Задачи

- [ ] Сектора 07–12 и биомы 3–4.
- [ ] Крио-маяк, акустический маяк, экзопехота и ремонтный бот.
- [ ] Сигнальный вожак, Глубинный титант.
- [ ] Двухобъектная оборона, последовательная разведка, многоэтапный финал.
- [ ] Расширение технологий и архива.
- [ ] Финальные брифинги и завершение сюжетной линии.
- [ ] Полный прогон кампании без фарма и с типичными улучшениями.

**Definition of Done:** все 12 секторов успешно завершаются; цель открытия всей карты достижима, финальная миссия имеет уникальную задачу и показано завершение кампании.

## 10. Приоритеты

**P0 — без этого нет игры:** стабильный запуск, тактическая симуляция, оборона, научная цель, победа/поражение, доступный интерфейс, сохранение и кампания.

**P1 — необходимо для MVP:** 6 секторов, экономика и звёзды, различимые виды врагов, ловушки, мобильный дрон, брифинги, технологии, портретный интерфейс.

**P2 — улучшение качества:** звуковые эффекты, расширенный архив, анимации лагеря, дополнительные настройки доступности.

**P3 — после MVP:** остальные 6 секторов, дополнительные классы отрядов и особые сценарии.

При нехватке ресурсов сокращать декоративный объём и уникальность художественных ассетов, **не** убирать обязательные игровые функции и не выдавать поломанную миссию за завершённую.

## 11. Сквозные приёмочные тест-кейсы

| ID | Действие | Ожидаемый результат |
|---|---|---|
| AT-01 | Новая игра → впервые открыть сектор 01 | Автоматический брифинг, начало с кадра 1 |
| AT-02 | Досмотреть/пропустить брифинг → выйти и зайти снова | Автобрифинг не повторяется |
| AT-03 | Нажать «Брифинг» после прохождения | Повтор с первого кадра, награды/миссия не сбрасываются |
| AT-04 | Победа в секторе 01 впервые | Награда 500 материалов/50 данных и доступ сектора 02 |
| AT-05 | Повторная победа в секторе 01 | Награда 180 материалов/20 данных, бонус не повторяется |
| AT-06 | Первая победа 1★, затем повтор 3★, затем поражение | Лучший результат остаётся 3★ |
| AT-07 | Поставить башню в единственный проходимый коридор | Операция отклонена до списания ЭС |
| AT-08 | Потратить точно доступную ЭС, затем попытаться купить ещё | Баланс 0, вторая покупка не производится |
| AT-09 | Пауза на 15 реальных секунд | Враги и учёные не перемещаются, таймеры не идут |
| AT-10 | Бой на 1× и 2× с одинаковой последовательностью игровых шагов | Равный исход и начисления |
| AT-11 | Обновить страницу после победы | Кампания, лучшие звёзды, ресурсы и исследования восстановлены |
| AT-12 | Подменить сохранение невалидным JSON | Приложение не падает, предлагается безопасный старт |
| AT-13 | Начать первый воздушный сектор | Зенитный пост уже гарантированно доступен |
| AT-14 | Разрушить критический генератор на кадре завершения монтажа | Результат один: поражение, без награды за победу |
| AT-15 | Развернуть мобильный экран с активной миссией | Камера перестроена; HP, время и ресурсы не сброшены |
| AT-16 | Тап по свободной строительной клетке | Предпросмотр; ЭС не списывается до подтверждения |
| AT-17 | Группа исследователей достигает точки эвакуации | Победа только после выполнения всех обязательных целей |
| AT-18 | Пройти все шесть секторов MVP | Завершение главы и честная пометка будущего контента |
| AT-19 | Пройти 12 секторов полного релиза | Финальный экран кампании и открытая карта |
| AT-20 | Убить врага двумя одновременными попаданиями | Награда за убийство начислена один раз |

## 12. Предлагаемый порядок работы через Git

- Создавать небольшие коммиты по логическим завершённым изменениям; понятные сообщения \`feat:\`, \`fix:\`, \`test:\`, \`docs:\`.
- Перед слиянием критических игровых изменений запускать тесты, проверку конфигов и соответствующие ручные сценарии.
- Для каждой новой миссии хранить конфиг, текст брифинга, условия звёзд и проверочный сценарий.
- Не смешивать переписывание движка с балансировкой миссий в одном изменении.
- Если вводятся несовместимые изменения сохранений, добавлять миграцию и соответствующий тест.
- Поддерживать отдельный список известных ограничений версии в README или релизных заметках.

## 13. Первый рекомендуемый рабочий набор задач

1. Создать минимальное приложение ES Modules с Canvas, responsive layout и тестовым экраном.
2. Реализовать модель поля и путь от входа к генератору.
3. Добавить одного врага, одну башню и начисление ЭС.
4. Собрать три волны сектора 01 в конфиге.
5. Добавить научный таймер и экран итогов.
6. Подключить лагерь, карту, брифинг, сохранение и первую награду.
7. Зафиксировать рабочий end-to-end сценарий AT-01 — AT-06.

После выполнения этих пунктов первая миссия станет **вертикальным срезом**, который можно тестировать на реальных игроках до масштабирования на шесть секторов.
